A Python chess engine built around minimax with alpha-beta pruning.

Chess programming involves many well-known techniques that are often poorly documented in accessible form. Sporkfish aims to bridge that gap — clear, working, readable code for developers who want to understand how chess engines actually work.

**Key features:**
- Minimax search with alpha-beta pruning
- Playable on [Lichess](https://lichess.org)

The name is a nod to Stockfish (currently the world's strongest engine), combining the chess *fork* move with *fish*.
